### A13.r1 (2026-11-20): implementation clarifications (before any A13 run)

Written after the A13 code and tests were built and before any run on the author's machine. No A13 audit or main result exists. Nothing in this text changes the grid, the methods, the thresholds, the decision table or the seeds of A13.

1. Slew matrix. The matrix of A13.2 is the shortest-path closure of the rounded matrix floor(c x |theta_i - theta_j| + 0.5), so that the triangle inequality holds exactly. Reason: with the triangle inequality, splitting a dwell never helps, which makes the class-aware oracle exact (item 3); the DP, the rules and the rollouts accept any matrix. The closure is not rare: in 2000 draws per case (n = 5, sandbox) it changed at least one entry in 61% (SPREAD, s_bar 2), 57% (SPREAD, 4), 30% (CLUSTER, 2) and 63% (CLUSTER, 4) of the instances, and the mean pairwise slew after rounding and closure was 1.83, 3.84, 1.84 and 3.77 against s_bar 2, 4, 2, 4. The tests require the mean to lie within 0.3 steps of s_bar. The constants c of A13.2 are unchanged. [CODE, sandbox]
2. Bearings. Own random stream keyed by (master seed, instance index, 13, geometry code). SPREAD: n independent uniform draws on [0, 1]. CLUSTER: n draws decide the group (group A with probability 1/2, centre 0.15, otherwise centre 0.85), n further draws give offsets uniform on [-0.05, 0.05]. Instance.s is s_bar; values, deadlines and priors come unchanged from `make_instance_k`.
3. Oracle. Exact deterministic optimum of every world by enumerating subsets and all orders of the subset; it is computed only in the audit rows (the main run records only the DP and the 11 methods) and is not used in a decision. Invariants in the audit: values within [0, V_dp], the exact value of the extracted DP policy equals V_dp, every rollout at least its base policy, oracle at least V_dp. In the main run the first, third and fourth are checked and the rest are not computed.
4. Decision details. Factor order for adjacency: n (4, 5), rho (1.1, 1.5), s_bar (2, 4), a (0.5, 0.9), geometry (SPREAD, CLUSTER). The bootstrap generator of a cell is seeded with the pair (20261242, cell number in this sorted grid order), so the result does not depend on the order in which the cells ran.
5. Reports without a decision. Share of instances in which the first action of the DP differs from that of CEP; Spearman correlation between the coefficient of variation of the instance slew matrix and the instance regret of the cell's best method; the control comparison on the audit.
6. Procedure. The author works on `main` only; the freeze of A13.12 is the commit that holds A13 and this text, made before the main run. The audits use the exploratory seed 1, stated explicitly. The gate hashes `src/dwell/m0g.py` and `scripts/run_a13.py` (line endings normalised); the main run and the control on the main seed are refused without a gate for the same hash.
7. Disclosure. In test runs in the sandbox (exploratory seed 1, 6 instances per cell, not the author's audit, not a result) the best of the 11 methods lost at most 3.3% in any cell and 0.43% on average, 0.27% in the uniform-slew control; a rollout was the best method in 94% of the cells; the first action of the DP differed from that of CEP in 43% of the instances. This is consistent with the expectation in A13.10 and changes nothing. [CODE, sandbox]
8. Cost (sandbox, one core, laptop speed not measured [OPEN]): about 0.13 s per instance in audit mode including the oracle, which puts the main run (6400 instances) at roughly a quarter of an hour on one core; no reduction of the instance counts is expected to be needed.
